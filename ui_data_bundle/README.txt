
CITYEPI-GPU UI DATA BUNDLE

Generated from the Kaggle CityEpi-GPU workspace.

Contents:
- synthetic/: generated population inputs and household data
- data/processed/geo/: processed Bengaluru OSM geographic layers
- data/boundaries/: Bengaluru Urban boundary
- epidemic_population_comparison/: legacy vs household results
- epidemic_transmission_sensitivity/: beta sensitivity results
- final_10seed_validation/: multi-seed results and statistics
- kaggle_v5/, kaggle_v6/: GPU benchmark artifacts

Important:
The population is synthetic and is not census data.
The household distribution and epidemic parameters are experimental assumptions.
The raw OSM PBF extract and build directories are intentionally excluded.
